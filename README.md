# public

Открытые проекты. Лицензия — [MIT](LICENSE).

| Проект | Назначение |
|---|---|
| [IR-optimizator/](IR-optimizator/) | Подготовка импульсных характеристик (IR) гитарных кабинетов для аппаратных загрузчиков с ограничением длины (Pangaea CP-16M и подобные): ресемплинг, обрезка, fade-out, нормализация по пику или громкости, анализ исходника и верности конвертации; сводка по IR в PNG; объединение двух IR — бленд кабинетов или свёртка «усилитель → кабинет» |

Каждый проект автономен: собственный `requirements.txt`, работа в виртуальном окружении:

```bash
cd IR-optimizator
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Подробности — в `README.md` каждого проекта.
