`tproxy-server` — **не собственный проект владельца этого репозитория.**

- Оригинал: [github.com/telegramdesktop/tproxy-server](https://github.com/telegramdesktop/tproxy-server) — «Proof-of-concept WEB proxy server for Telegram», автор John Preston (Telegram Desktop).
- Эта копия перенесена из форка [github.com/ststitov/tproxy-server](https://github.com/ststitov/tproxy-server) вместе с полной историей git, чтобы сохранить авторство: 28 коммитов оригинала и один собственный — проверка режима доступа к файлу профилей в тесте конфигурации (`internal/config/config_test.go`).

Актуальная версия и условия использования — в оригинальном репозитории.
